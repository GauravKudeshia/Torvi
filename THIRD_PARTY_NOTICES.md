## Reference repositories

The following repositories were reviewed as public compatibility/product references. No source has been copied into this repository.

- [OpenCluely](https://github.com/TechyCSR/OpenCluely) — MIT. Useful public concepts: cross-platform overlay constraints, optional local/cloud speech providers, clear permission troubleshooting.
- [NexQ](https://github.com/naxhq/NexQ) — MIT. Useful public concepts: Tauri feasibility, WASAPI loopback, provider capabilities, explicit audio modes.
- [Project Raven](https://github.com/Laxcorp-Research/project-raven) — MIT. Useful public concepts: dual-channel capture, echo cancellation as a dedicated stage, bounded local session memory, and best-effort content-protection disclosure.
- [Natively](https://github.com/Natively-AI-assistant/natively-cluely-ai-assistant) — current Natively Personal Use Source License v1.0; not open source and not commercially compatible. Its code, architecture, prompts, workflows, and assets are excluded from this implementation.
